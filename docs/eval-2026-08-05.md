# MODEL_SYNTH eval — 2026-08-05

First bake-off run: 3 companies (starter set) × 3 candidate synthesizers, all synthesized from
identical research bundles (Parallel `pro` + Exa passes), judged blind (models anonymized as
A/B/C, label order varied per company), then fact-checked against the live web. Total research +
synthesis spend: $2.11. All 9 briefs persisted as `artifacts` kind=eval in Supabase.

Why opus-5: it consistently made the editor calls the PRD cares about — it alone flagged that
E2B's company-reported traction figures are mutually inconsistent, disambiguated a same-name
founder profile, labeled a database-only funding row "(database listing only)", and distinguished
press-sourced vs database-sourced funding leads at Physical Intelligence. Its extra length was
signal, not padding. Kimi-k3 writes the tightest prose and won Daytona on preserving the
pivot/traction story, but committed the run's worst factual error (flatly asserting wrong funding
leads at PI against its own cited source). Qwen3.8-max was consistently competent but thin —
lost signal (dropped rounds, single-item news sections) without gaining accuracy.

## Fact-check findings → prompt changes applied

1. **Aggregator-database funding rows are the top accuracy risk.** Both briefs that included
   E2B's 2023 round mislabeled it (Tracxn "Seed $2.5M" vs press "~$3M pre-seed led by Kaya +
   Sunflower"). → A2 prompt now requires "(database listing)" labeling, caps such rows at
   medium confidence, and forbids promoting database participants to leads.
2. **Placeholder text in lead_investors** ("Lead not stated" rendered into a bullet). → A2 now
   requires an empty array when the lead isn't named.

Everything else checked accurate: E2B Series A ($21M Insight, 2025-07-28), GitHub stats for
e2b/openpi (live-API verified), all three Daytona rounds, founder backgrounds (Hausman CV,
Burazin timeline, Valenta/Masaryk).

## Caveats

- Starter eval set (3 well-covered companies I picked) — replace with 10–15 real companies from
  recent calendars, including a stealth company and a name-collision case, and re-run before
  treating this as settled. `daybrief eval` re-uses EVAL_SYNTH_MODELS from .env.
- Single judge + single fact-checker per company; the harness supports more when the real set runs.
